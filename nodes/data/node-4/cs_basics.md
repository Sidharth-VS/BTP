# Computer Science & Distributed Systems Architecture

## Byzantine Fault Tolerance (BFT)
In distributed computing, Byzantine Fault Tolerance is the dependability of a fault-tolerant computer system where components may fail and there is imperfect information on whether a component has failed. The objective is to defend against Byzantine failures where actors can arbitrarily forge, omit, or send conflicting transactions to different peers.

## Number Theoretic Transform (NTT) in Cryptography
The Number Theoretic Transform is a specialized discrete Fourier transform computed over finite fields. In lattice-based post-quantum cryptography algorithms such as ML-KEM and ML-DSA, NTT accelerates ring polynomial multiplication from quadratic O(n^2) complexity to O(n log n) complexity.

## Vector Database Indexing
Hierarchical Navigable Small World (HNSW) graphs organize vectors into a multi-layered geometric graph. Upper layers contain sparse connections for coarse navigation, while lower layers contain dense clusters for fine-grained nearest-neighbor retrieval.
